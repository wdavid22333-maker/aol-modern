# AOL Modern Interface

A modern web interface for AOL that works seamlessly with existing AOL authentication.

## Features

- Dark theme interface similar to Codes
- No need to sign in again if you're already logged in to AOL in another tab
- Access to email, chat, and forums with a modern UI
- Responsive design that works on all devices

## How It Works

This interface leverages existing AOL authentication cookies and sessions. When you're already logged in to AOL in another tab, this interface can access your AOL services without requiring you to sign in again.

## Development

To run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment

This project can be deployed to any platform that supports Next.js, such as Vercel, Netlify, or Railway.
